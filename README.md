# HomeHub

HomeHub is a private, self-hosted home automation dashboard used only by its owner, Richard Wildey.
It runs on the owner's own computers and controls lights, thermostats and other devices on the home network.

HomeHub is not a public service, is not offered to other users, and has no accounts or sign-ups.
