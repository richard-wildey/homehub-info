# HomeHub Privacy Policy

_Last updated: November 19, 2026_

HomeHub is a private app used only by its owner. It is not available to the public.

**Data accessed:** HomeHub uses Google's Smart Device Management (Nest) API to read and control
the owner's own Nest devices (for example, thermostat temperature and mode).

**How data is used:** Device data is used only to display status and send commands from the
owner's dashboard.

**Storage and sharing:** Nest data stays on the owner's own computers. It is never sold, shared,
or sent to any third party, and is not used for advertising or analytics.

**Revoking access:** Access can be removed at any time at
https://myaccount.google.com/permissions.
